# Synorch v0.1.0

Synorch's first public release turns an empty directory, an existing repository, or a multi-repository workspace into a provider-neutral AI collaboration structure for Codex and Claude Code.

## Highlights

- A control-plane-first architecture where the orchestrator plans, delegates, verifies, and reports without implementing product changes itself.
- Safe, repeatable `inspect`, `init`, `sync`, and `doctor` commands.
- Evidence-driven project discovery that records verified stacks, commands, modules, and package managers.
- Automatic activation of focused React, Java, Spring Boot, JPA, Node.js, Vue, Nuxt, and Tailwind skills.
- A curated 33-skill Ingenium library with source, license, and provenance metadata and strict on-demand loading.
- Minimal context and completion packets designed to reduce repeated repository scans and token usage.

## Install and run

Without a global installation:

```bash
npx synorch init
npx synorch sync
npx synorch doctor
```

Or install the short command globally:

```bash
npm install --global synorch
syn init
```

Node.js 24 or newer is required.

## Current boundaries

- Synorch generates the orchestration structure; it is not a persistent model runtime or agent harness.
- Project discovery is manually refreshed with `syn sync`.
- `yarn create synorch` is not part of this release; use `yarn dlx synorch init`.
