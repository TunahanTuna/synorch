# Synorch v0.2.0

Synorch v0.2.0 makes orchestration proportional: small changes stay small, while high-risk work keeps the evidence and independent review it needs. The release also promotes Task Conductor to a provider-neutral canonical skill and sharply separates available, active, and task-loaded skills.

## Highlights

- Classifies work as `trivial`, `standard`, or `high-risk` before expanding the workflow.
- Routes trivial changes to one fast worker with a compact approved plan and claim-specific proof.
- Prevents routine full-project checks, independent review, or headed-browser verification for trivial work.
- Keeps browser verification opt-in unless the user approves it for a named criterion that cheaper evidence cannot settle.
- Makes Task Conductor the eighth canonical base skill and the central decomposition and skill-routing discipline for non-trivial briefs.
- Loads skills just in time instead of scanning the complete catalog during session bootstrap.
- Distinguishes catalog skills that are `available`, project skills that are active, and skills actually loaded for a task.
- Hardens npm Trusted Publishing by invoking a pinned npm 11.19.1 CLI in the release workflow.

## Contract changes

Task context packets now require:

- `risk_tier`
- `verification_commands`
- `review_required`
- `browser_policy`
- `loaded_skills`

Worker completion packets now report `checks_skipped` and `loaded_skills`. Project skill registries contain eight canonical base skills instead of seven.

## Upgrade an existing Synorch structure

Commit or back up the target repository first. Then inspect and regenerate the canonical files:

```bash
npx synorch@0.2.0 inspect --target .
npx synorch@0.2.0 init --target . --force
npx synorch@0.2.0 sync --target . --force
npx synorch@0.2.0 doctor --target .
```

Review the resulting diff before committing it. The `--force` flags intentionally replace modified generated files, so do not use them before preserving project-specific customizations.

## Start a new structure

```bash
npx synorch@0.2.0 init
npx synorch@0.2.0 sync
npx synorch@0.2.0 doctor
```

Or update the global CLI:

```bash
npm install --global synorch@0.2.0
syn --version
```

Node.js 24 or newer is required.
