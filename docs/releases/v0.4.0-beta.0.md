# Synorch v0.4.0-beta.0

Synorch v0.4.0-beta.0 is the first beta of the `syn` harness: a conversation-first coding agent in the terminal that talks to several providers, orchestrates isolated workers and has their work reviewed independently by a different provider. The 0.3.0 structure commands (`inspect`, `init`, `sync`, `doctor`) keep working unchanged.

This is a pre-release published under the npm dist-tag `beta`. `npx synorch` and `npm i -g synorch` still resolve to 0.3.0.

## Highlights

- Bare `syn` opens an interactive agent session, like `claude`; no `syn init` is needed and it works from any directory.
- Multi-provider: sign in with a ChatGPT subscription, use the local Claude Code CLI through a bridge that keeps its native toolset, or bring API keys.
- Orchestration with isolated workers in separate worktrees and an independent, cross-provider review of every change; orchestration can run in the background while you keep talking.
- `/review` runs the independent review on demand, with a pinned review artifact, a verdict card and a fix follow-up.
- Permission modes `ask`, `auto`, `full` and `plan`: risky actions ask for approval instead of failing silently.
- MCP client with OAuth for remote servers.
- Skills, slash commands and plugins compatible with Claude Code, including plugin hooks and agents.
- Effort control, themes, a welcome screen and logo, and layered panels for skills, plugins, MCP, status, runs, memory, config and help.
- `/rewind` and `/fork` to go back in or branch a conversation.

## Install the beta

```bash
npm install --global synorch@beta
syn --version   # 0.4.0-beta.0 (<commit>)
syn
```

Or run it without installing:

```bash
npx synorch@beta
```

To go back to the stable release, run `npm install --global synorch@latest`.

Node.js 24 or newer is required.

## Known limitations

- This is a beta. Expect rough edges and breaking changes before 0.4.0.
- Not every feature has been validated in real terminals yet; please report terminal-specific rendering or input problems.
- One test is flaky on the Windows CI runner.
